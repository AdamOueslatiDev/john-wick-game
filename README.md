# John Wick Game

A complete 2D game developed in C using SDL2 and designed to run on Linux.

## 🎮 About the Game

This project is a complete interactive game featuring multiple levels, enemies, puzzles, combat, menus, scoring, and an interactive gameplay system.

The game combines platforming, combat, exploration, and puzzle-solving elements.

## ✨ Features

- Multiple game levels
- Player movement and combat
- Enemy characters with animations
- Different enemy types
- Puzzle and quiz systems
- Health/life system
- Score system
- Save and load functionality
- Interactive menus
- Sound effects and music
- Animated characters
- Different game modes and options

## 🛠️ Technologies

- C
- SDL2
- SDL_image
- SDL_ttf
- Linux

## 📁 Project Structure

- `main.c` — Main program
- `game.c` / `game.h` — Game logic
- `images/` — Game graphics, animations, UI and audio assets
- `enigmes.txt` — Puzzle/quiz data
- `histoire.txt` — Story content
- `arial.ttf` — Game font

## 🖥️ Platform

This project was developed and tested on **Linux**.

## 🚀 Running the Project

Make sure the required SDL2 libraries are installed on your Linux system.

Compile the project using GCC and the required SDL2 libraries, then run the generated executable.
